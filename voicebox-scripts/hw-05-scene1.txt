Si la app usa tu input para elegir qué archivo incluir, controlás el archivo, y a veces mucho más. Path traversal te deja escapar de la carpeta web; el LFI lleva eso más lejos y lee archivos del servidor en el peor lugar posible. El servidor web expone solo una carpeta, pero un endpoint que sirve archivos por nombre puede aceptar punto punto barra para subir por el árbol. Punto punto barra repetido cuatro veces y etc barra passwd escala directorios y lee el archivo de cuentas: el servidor une la ruta a ciegas y devuelve etc barra passwd en vez de una página. Unos pocos punto punto te llevan a la raíz, y después agregás la ruta absoluta que quieras.
