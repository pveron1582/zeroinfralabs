Android usa un kernel Linux modificado. De hecho, la mayoría de los dispositivos Linux del mundo son Android. Si conectás el teléfono y escribís adb shell, tenés una shell Linux real: los mismos ls, cd, ps y cat. Las diferencias: las apps corren sandboxeadas, se ejecutan en una máquina virtual llamada ART, y por defecto no hay root. El root se consigue con herramientas como Magisk o instalando ROMs como LineageOS. Para pentesting importa: testing de apps móviles, adb, Frida para instrumentar, todo corre sobre la base Linux que ya conocés.
