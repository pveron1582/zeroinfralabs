Y no terminan ahí los protocolos. Web socket mantiene una conexión bidireccional y persistente: chats, trading, dashboards en tiempo real. Web DAV edita archivos en el servidor por HTTP, a veces olvidado con autenticación débil. REST, o APIs, mueve JSON sobre HTTP, el idioma de las apps modernas. Y cuidado: el DNS también puede ser un protocolo de ataque, para filtrar datos adentro de consultas DNS. Para ver todo esto en la práctica, un simple curl menos i te muestra las cabeceras del servidor: ahí descubrís qué software corre y qué versión, el primer dato para elegir un exploit.
