El caso más famoso es saltarse el login. Una consulta de acceso arma algo como select de users donde username igual comillas y password igual comillas. Si mandás comilla espacio o espacio uno igual uno como usuario, la condición queda siempre verdadera, y el servidor te deja pasar como la primera fila, a menudo admin. En la práctica, un curl con usuario admin comilla espacio o espacio uno igual uno devuelve bienvenido admin: las comillas cierran el string y el o uno igual uno vuelve la condición una tautología que devuelve al primer usuario.
