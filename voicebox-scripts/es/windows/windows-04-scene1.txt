En Linux, todo cuelga de un solo árbol. Windows es distinto: cada disco es un árbol propio, y la estrella es C dos puntos. Adentro, Windows System32 es el núcleo del sistema; Windows Temp es escribible por todos, y los atacantes lo adoran. En Users viven los perfiles de cada usuario: Desktop, Documents, Downloads. Program Files tiene las aplicaciones, e inetpub, wwwroot, es la raíz web de IIS. Ojo: las ACL solo existen en NTFS; en discos FAT32 no hay permisos de archivos.
