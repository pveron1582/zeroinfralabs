Un script que hace siempre lo mismo no sirve. Lo bueno empieza cuando tu script se adapta al objetivo: le pasás un host y decide qué hacer. Para eso necesitás tres piezas: variables para guardar datos, argumentos para recibirlos desde afuera, y condicionales para elegir el camino. Con esas tres cosas, tu script deja de ser una lista fija de comandos y se convierte en una herramienta que piensa.
