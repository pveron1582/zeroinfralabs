Los comandos de PowerShell se llaman cmdlets, y siguen el patrón verbo guion sustantivo: Get Process, Get Service, Set Item. El pipeline, el pipe, pasa objetos entre ellos. Por ejemplo, Get Process pipe Sort Object CPU Descending ordena los procesos por su propiedad CPU. Filtrás con Where Object, y elegís campos con Select Object. En bash parsearías texto; acá manipulás objetos directo.
