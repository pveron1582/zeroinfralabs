La escalada final es de LFI a ejecución remota de código. Si el servidor escribe tus peticiones en un log y podés incluir ese log, metés código PHP en una línea y el include lo ejecuta. User agent dos puntos menor signo menor interrogación php system get cmd mayor signo mayor aterriza en el access log; después lo incluís y llamás cmd igual id. Un archivo que nunca debía ser código ejecuta el tuyo, y ganás una shell. Para defender: nunca meter input del usuario en rutas de include u open, validar contra una lista blanca, y correr el servidor web con el menor privilegio posible.
